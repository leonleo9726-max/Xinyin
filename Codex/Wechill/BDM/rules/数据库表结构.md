# BDM 数据库表结构

> MySQL，查询前先 `SHOW COLUMNS FROM <表名>`（当前版本不支持 `DESC`）

> **生产库 schema**：`mysql_prod` 默认连接为 `information_schema`；查询业务表必须使用 `dy.<table_name>`（如 `dy.app_user_agency_member`）。

## 枚举速查

| 表 | 字段 | 枚举映射 |
|------|------|------|

| `bd_staff` | `employment_status` | 0=试用，1=转正，2=离职 |

| `bd_staff` | `record_status` | 0=作废，1=正常 |
| `bd_staff_monthly_salary` / `bd_staff_monthly_salary_detail` / `bd_realtime_staff_salary` | `salary_role` | 1=BD个人薪资，2=BDM团队管理薪资 |

| `app_payer_trader` | `recharge_status` | 0=不可充值，1=可充值 |
| `app_payer_trader` | `trading_status` | 0=不可交易，1=可交易 |
| `app_payer_trader` | `status` | 0=无效，1=有效 |

| `app_payer_trader_coin_frozen_detail` | `frozen_status` | 0=冻结，1=扣除，2=归还 |
| `admin_content_official_trader_coin_detail` | `type` | 1=赠送，2=扣除 |

| `app_user_agency` | `coin_collect` | 0=否，1=是 |
| `app_user_agency_member` | `status` | 0=无效，1=有效 |
| `app_user_agency_member` | `role` | 0=公会长，1=公会管理员/运营，2=普通成员/主播 |
| `app_user` | `status` | 0=禁用，1=启用，2=注销（来自 `SHOW CREATE TABLE app_user` 字段注释） |
| `app_user_login` | `registered` | 0=登录事件，1=注册事件（来自 `SHOW CREATE TABLE app_user_login` 字段注释“是否为注册”） |
| `bd_agency_bind` | `bind_status` | 0=已解除，1=绑定中 |
| `bd_agency_bind_log` | `event_type` | 1=绑定，2=解绑，3=换绑，4=修改绑定生效时间 |
| `bd_level_config_main` | `policy_type` | 0=BD政策，1=BDM政策 |
| `bd_level_config_main` | `status` | 0=禁用/停用，1=使用中/可绑定 |
| `bd_guild_apply` | `apply_status` | 0=审核中，1=已通过，2=已拒绝 |
| `bd_guild_apply_audit` | `auditor_type` | 1=BDM，2=平台 |
| `bd_guild_apply_audit` | `audit_result` | 1=通过，2=拒绝 |
| `bd_staff_monthly_salary_issue` | `issue_status` | 1=待处理，2=已解决，3=已忽略 |
| `app_user_flag` | `audit_status` / `verified_audit` / `official` | `verified_audit`/`official`: 0=否，1=是；`audit_status`: 0=否，1=是，2=默认值/语义待确认 |

## 币商管理

|------|------|------|
| trader_id | int PK | 币商ID |
| admin_user_id | int | 绑定的管理用户ID |
| agency_id | bigint UNI, NULL | 关联公会ID；每个公会最多一个币商 |
| user_id | bigint | 币商用户ID，关联 `app_user.user_id` |

| frozen_send_coin | bigint | 已冻结赠送金币 |
