# 充值活动相关字段

| 表 | 字段 | 已核实含义 |
|---|---|---|
| `app_payer_recharge_detail` | `price` | 美元价格；统计实际充值金额用此字段 |
| `app_payer_recharge_detail` | `status` | `0` 处理中，`1` 失败，`2` 成功，`3` 退款，`4` 退款（谷歌支付） |
| `app_payer_recharge_detail` | `success_time` | 充值成功时间；按月统计使用左闭右开时间范围 |
| `app_payer_recharge_detail` | `user_id` | 关联 `app_user.user_id` 和 `app_user_flag.user_id` |
| `app_user_flag` | `region` | 用户所属区域；`0` 英语区，`2` 中东区，`3` 土耳其区 |
| `app_act_rank_data` | `score` | 活动榜单分数，不是美元价格；每笔充值可能按多个 `rank_type` 写入 |

`app_act_config.region` 的 `0`、`2` 分别对应英语区和中东区；`app_user_flag.region` 的其他值需按业务配置核实。
