# Risk 数据库表结构

> 本文件仅记录已通过 `SHOW COLUMNS` 核实的字段与本次查询确认的映射；未查询的风险表字段不预填。

## `app_user_ban` - 当前账号封禁状态

| 字段 | 类型 | 已确认用途 |
|---|---|---|
| `ban_id` | `bigint` | 封禁记录主键。 |
| `user_id` | `bigint` | 被封禁账号，与 `app_user.user_id`、`app_user_agency_member.user_id` 关联。 |
| `status` | `tinyint` | 本次数据确认：`1` 为当前有效封禁，`0` 为已解除。 |
| `ban_type` | `int` | 封禁类型；已观测值 `6`，具体语义待确认。 |
| `ban_reason_type` | `smallint` | 封禁原因类型；已观测值 `1002` 对应备注中的 IP 默认限制，正式枚举待确认。 |
| `unique_id` | `varchar(64)` | 关联唯一标识，具体对象语义待确认。 |
| `ip` | `varchar(64)` | 关联 IP。 |
| `expired_time` | `datetime(3)` | 封禁到期时间。 |
| `unban_time` | `datetime` | 解封时间。 |
| `unban_remark` | `varchar(512)` | 解封备注。 |
| `remark` | `varchar(512)` | 封禁备注。 |
| `ban_image` | `varchar(512)` | 封禁证据图片路径。 |
| `admin_user_id` | `int` | 操作后台用户；可关联 `admin_content_user.admin_user_id` 获取用户名与实名。为空时，该封禁记录无法归属具体后台操作人。 |
| `manager_user_id` | `bigint` | 操作管理用户，具体关联待确认。 |
| `create_time` / `update_time` | `datetime(3)` | 创建与最近更新时间。 |
| `app_type` | `smallint` | 应用类型，具体枚举待确认。 |

## `app_user_ban_detail` - 封禁明细历史

| 字段 | 类型 | 已确认用途 |
|---|---|---|
| `detail_id` | `bigint` | 明细主键。 |
| `user_id` | `bigint` | 被封禁账号。 |
| `ban_type` / `ban_reason_type` | `tinyint` / `smallint` | 封禁类型与原因类型；具体枚举待确认。 |
| `unique_id` / `ip` | `varchar(64)` / `varchar(64)` | 关联唯一标识与 IP。 |
| `remark` / `ban_image` | `varchar(512)` / `varchar(512)` | 封禁备注与证据图片路径。 |
| `expired_time` | `datetime(3)` | 此次封禁的到期时间。 |
| `unban_time` / `unban_remark` | `datetime` / `varchar(512)` | 此次明细的解封记录。 |
| `admin_user_id` / `manager_user_id` | `int` / `bigint` | 操作人字段；`admin_user_id` 可关联 `admin_content_user.admin_user_id`，`manager_user_id` 的关联表待确认。 |
| `create_time` | `datetime(3)` | 明细创建时间。 |
| `app_type` | `smallint` | 应用类型，具体枚举待确认。 |

> `app_user_ban_detail` 同一 `user_id` 可存在多条历史明细，不能仅按账号直接更新全部历史记录；当前封禁状态以 `app_user_ban` 为准。

## 关联查询表

| 表名 | 已确认字段 | 本次用途 |
|---|---|---|
| `app_user` | `user_id`、`user_number`、`nickname`、`status`、`update_time`、`create_time` | 账号主状态；本次数据确认 `status=1` 为正常。 |
| `app_user_agency_member` | `member_id`、`agency_id`、`user_id`、`status`、`role`、`join_time`、`exit_time`、`admin_user_id`、`create_time`、`update_time`、`settlement_policy_type`、`next_settlement_policy_type` | 按 `agency_id` 确定当前公会成员；本次范围使用 `status=1`。 |
| `admin_content_user` | `admin_user_id`、`user_id`、`username`、`real_name`、`status`、`create_time`、`update_time` | 后台操作人身份；通过 `admin_user_id` 关联封禁记录。 |
| `admin_content_log` | `log_id`、`admin_user_id`、`url`、`params`、`method_name`、`http_method`、`create_time` | 后台接口审计日志；可按封禁发生时间、对象 ID 和接口路径追溯人工操作。 |

## `app_user_device` - 账号设备快照

| 字段 | 类型 | 已确认用途 |
|---|---|---|
| `user_id` | `bigint` | 账号主键，与 `app_user.user_id` 关联。 |
| `unique_id` / `first_unique_id` | `varchar(64)` | 当前与首次设备唯一标识。 |
| `os_model` / `os_version` | `varchar(64)` / `varchar(40)` | 设备型号与操作系统版本。 |
| `app_version` / `build_version` | `varchar(20)` / `int` | 客户端版本与构建号。 |
| `ip_address` / `ip_country` | `varchar(64)` / `varchar(50)` | 当前或最近更新的 IP 与国家。 |
| `first_ip_address` / `first_ip_country` | `varchar(64)` / `varchar(50)` | 首次记录 IP 与国家。 |
| `update_time` | `datetime(3)` | 设备快照最近更新时间；不等同于完整登录流水。 |
| `app_type`、`first_variant_type`、`variant_type`、`download_channel`、`ip_longitude`、`ip_latitude` | `smallint` / `smallint` / `smallint` / `smallint` / `decimal(12,8)` / `decimal(12,8)` | 应用、渠道与 IP 地理信息字段；具体枚举待确认。 |

## 充值风控

| 表名 | 已确认字段 | 已确认用途 |
|---|---|---|
| `app_payer_recharge_ban` | `ban_id`、`user_id`、`unique_id`、`limit_type`、`status`、`expired_time`、`reason`、`remark`、`operator_id`、`created_at`、`updated_at` | 账号/设备充值限制的当前配置；`limit_type` 枚举语义以 `核心业务规则.md` 为准。`status` 的有效值语义待代码或数据确认。 |
| `app_payer_recharge_ban_log` | `id`、`user_id`、`limit_type`、`reason`、`remark`、`operator_id`、`created_at` | 充值限制操作历史；只记录账号维度，设备关联需通过 `app_payer_recharge_ban` 或设备表补充。 |
| `app_payer_recharge_whitelist` | `id`、`user_id`、`os_type`、`operator_id`、`reason`、`created_at`、`removed_at` | 充值账号白名单；`removed_at IS NULL` 的当前有效判定尚待确认。 |
| `app_payer_device_recharge_summary` | `unique_id`、`official_total_usd`、`total_recharge_usd`、`update_time` | 设备充值汇总；官方累计与全量累计分别存储。 |
| `app_payer_recharge_detail` | `id`、`user_id`、`unique_id`、`recharge_type`、`provider_type`、`channel_type`、`platform_type`、`price`、`status`、`create_time`、`success_time` | 单笔充值记录；`status` 枚举及各渠道字段枚举待确认，不得仅按数值推断支付结果。 |

## `app_common_device_imei` - 通用设备标识

| 字段 | 类型 | 已确认用途 |
|---|---|---|
| `unique_id` | `varchar(64)` | 主键、非空的设备唯一标识。 |
| `platform_type` | `smallint` | 平台类型，具体枚举待确认。 |
| `uuid`、`gaid`、`device_id`、`widevine_id`、`idfv`、`idfa`、`adid` | `varchar(64)` | 各类设备或广告标识；允许为空。 |
| `download_channel` | `smallint` | 下载渠道，具体枚举待确认。 |
| `create_time` / `update_time` | `datetime(3)` | 创建与更新时间。 |

## 登录流水

| 表名 | 已确认字段 | 用途 |
|---|---|---|
| `app_user_login` | `login_id`、`user_id`、`unique_id`、`login_type`、`registered`、`app_type`、`variant_type`、`app_version`、`build_version`、`os_model`、`os_version`、`ip_address`、`create_time` | 逐次登录记录。查询最近一次登录设备应按 `create_time DESC, login_id DESC` 取首条，不应以 `app_user_device.update_time` 替代。 |
| `app_user_login_detail` | `log_id`、`user_id`、`login_time`、`logout_time`、`active_duration` | 登录会话时段与活跃时长；未保存设备 ID。 |
