|:---|:---|:---|
| Withdrawable balance | 可提现金额 = 主播往期已结算工资余额 + 主播往期已结算 TG 奖励余额 |

## 2. 公会长视角

### 2.1 公会页面（My Agency）

#### Agency current salary（公会当前薪资）
| 字段 |
|:---|
| Agency total Salary |
| Agency total Salary Balance |
| All hosts Salary |
| Agent Commission |
- 公会总工资=主播工资+主播TG+公会长工资+公会长TG
- 公会工资余额=公会总工资-公会预支欠款（字段值不会为负数）
- 所有主播薪资=主播工资+主播TG奖励（不包含公会长作为主播的工资跟tg奖励）
- 公会长工资=公会长薪资+公会长TG奖励(不包含公会长作为主播的工资跟tg奖)

#### 公会预支
| 字段 |
|:---|
| Agency Advance Salary |
| Agent borrowed amount |
| Agent borrowable amount |
- 公会已预支欠款金额=公会长预支欠款+主播预支欠款
- 公会长本期借支金额：仅统计当前结算周期内的借支，结算后清零；未还清部分结转至历史欠款
- 公会长可借支金额=**直接读** `app_user_agency.borrowable_amount`（美元），字段为滚动余额（借支审批时已原子扣减，结算还款时加回），切勿再做动态减法

#### Agent as host Salary（主播身份薪资）
| 字段 |
|:---|
| Agent total salary |
| Agent as host Salary |
| Agent borrowed amount |
| Agent as host Advance Salary |
| Agent Salary Balance |
- 公会长总工资=公会长工资+公会长TG+公会长作为主播工资+公会长作为主播TG
- 公会长作为主播收入=公会长作为主播工资+公会长作为主播TG奖励
- 公会长借支金额（本期）
- 公会长预支金额
- 公会长工资余额=公会长总工资-公会长预支金额（不再减借支，借支与薪资独立）

#### 公会长盈余模块
| 字段 |
|:---|
| 本期盈余 |
| 本期薪资 |
| 本期借支 |
| 本期实际工资 |
| 历史欠款 |
- 本期薪资 = 公会长作为主播的薪资 + 作为主播的TG奖励 + 公会提成（TG+分成）= 公会长总工资 - 本期预支
- 本期借支：本期内最后一次结算之后的借支金额。查 `admin_content_agency_borrow_salary_log`（type=1，金额美元），结算后清零，未还部分体现为历史欠款
- 本期实际工资 = 本期薪资 - 本期借支 - 历史欠款
- 历史欠款：取 `app_payer_agency_owner_surplus` 最新一条归档，若 `period_actual_salary < 0` 则为 `ABS(period_actual_salary)`，否则为 0。数据来源为盈余归档表，金色底色标识
- 结算结转规则：本期实际工资 < 0 → 本期薪资/借支/实际工资三者清零，差额结转至下期历史欠款；本期实际工资 >= 0 → 下期历史欠款 = 0
- 结算类型：系统结算（双周政策）/ 手动结算（自由政策，确认弹窗含历史账单记录）

#### Wallet（钱包）
| 字段 |
|:---|
| Withdrawable balance |
| 个人账户余额 |
| 主播转入 |
- 可提现余额拆分为两个独立账户：**个人账户余额**（公会长自有薪资）和**主播转入**（主播提现转给公会长）
- 提现成金币：默认选择个人账户，提现上限为所选账户全部余额
- 提现到银行卡：默认不选账户，用户手动选择，上限为所选账户全部余额
- 原"全部"按钮已取消；若提现金额超过单一账户上限，需拆分多笔
