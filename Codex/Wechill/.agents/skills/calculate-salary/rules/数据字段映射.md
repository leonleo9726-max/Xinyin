# 数据字段映射规则

## 核心映射

| 字段 | 用途 | 说明 |
|:---|---:|:---|
| `gain_diamond + send_gain_diamond` | **主播薪资计算基数** | 主播档位判定 + 超档基数 |
| `gain_coin` | **公会长分成计算基数** | 公会长档位判定 + 超档基数 |

> **会长佣金基数 = `gain_coin`**

## 每人同时计算两项

无论用户的 `role` 是 0（公会长）还是 2（主播），每个用户都需要同时计算：

1. **主播薪资** — 用该用户的 `gain_diamond + send_gain_diamond`
2. **公会长分成** — 用 `gain_coin`

两项叠加为该用户的总收入。

## 档位独立判定

- **主播档位**: 根据 `gain_diamond + send_gain_diamond` 查档位 → `host_salary` / `host_tg_reward` / 超档门槛
- **会长档位**: 根据 `gain_coin` 查档位 → `agency_owner_salary` / `agency_owner_tg_reward` / 超档门槛
- 两者可处于不同档位，互不影响

## 超档佣金差异

| 政策 | 主播超档佣金 | 公会长超档佣金 |
|:---|:---:|:---:|
| **自由政策** | 超档单位 × 0.75 | 超档单位 × 0.25 |
| **双周政策** | 超档单位直接计为佣金（不乘系数） | 无超档佣金 |

## 无门槛规则（所有政策通用）

- 当钻石数**未达到最低档位（Level 1）**时，基础薪资和 TG 奖励均为 **$0.00**
- 超档从 **0** 起算（全部钻石视为超档）：`over = diamonds - 0 = diamonds`
- 超档佣金按各政策正常系数计算
- 即：**未达档 = 纯超档佣金**（无基础 + 无 TG）
