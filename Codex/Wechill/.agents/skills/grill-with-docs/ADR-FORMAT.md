# ADR Format

Create an ADR only for decisions that are hard to reverse, surprising without context, and the result of a real trade-off.

## File

Use `docs/adr/NNNN-short-title.md`, with the next available number.

## Template

```markdown
# ADR NNNN: Title

## Status

Accepted

## Context

What forces made this decision necessary.

## Decision

The choice made.

## Alternatives Considered

- Alternative: why rejected.

## Consequences

- Positive consequence.
- Negative or follow-up consequence.
```

Keep ADRs short and decision-focused.
