# Out-of-Scope Knowledge Base

Use `.out-of-scope/` to avoid re-litigating rejected enhancement requests.

## When to Write

Write an entry when an enhancement is closed as `wontfix` for a reason future triage should know.

## File Format

```markdown
# Title

## Request

What was requested.

## Decision

Why it is out of scope.

## Revisit If

Concrete conditions that would make the decision worth reopening.

## Source

Issue or discussion link.
```

Do not use this for bugs, temporary deferrals, or vague "not now" decisions.
