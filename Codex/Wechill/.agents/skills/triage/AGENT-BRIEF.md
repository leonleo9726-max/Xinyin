# Agent Brief

Use this structure when posting a `ready-for-agent` or `ready-for-human` issue comment.

```markdown
> *This was generated by AI during triage.*

## Agent Brief

### Goal

What should be changed, in user-visible or caller-visible terms.

### Context

Relevant domain terms, prior decisions, and issue discussion summary.

### Current Behavior

What happens now.

### Desired Behavior

What should happen after the work.

### Acceptance Criteria

- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

### Constraints

Important files, APIs, ADRs, data rules, or manual checks.

### Suggested Verification

Commands or checks an agent can run.
```

Keep the brief durable: avoid stale implementation guesses when behavior-level wording is enough.
