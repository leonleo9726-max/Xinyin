# 1.1.5-1.1.7 综合PRD 测试用例

> 生成时间：2026-08-07
> 需求来源：1.1.5-用户资料与直播间PRD.md；1.1.6-消息与资产商城PRD.md；1.1.7-等级互动与UI优化PRD.md

## 1. 个人资料页基础展示
### 1.1 入口、加载与访问状态
- 1.1.1 用户从搜索结果点击用户时，系统进入该用户个人资料页。
- 1.1.2 用户从榜单点击用户时，系统进入该用户个人资料页。
- 1.1.3 用户从聊天页点击用户资料入口时，系统进入该用户个人资料页。
- 1.1.4 用户从房间用户卡片点击用户时，系统进入该用户个人资料页。
- 1.1.5 用户从支持者卡片点击用户时，系统进入该支持者个人资料页。
- 1.1.6 用户从动态入口点击用户时，系统进入该用户个人资料页。
- 1.1.7 当前用户查看自己的个人资料页时，页面按本人资料口径展示。
- 1.1.8 当前用户查看他人个人资料页时，页面展示关注和私信等社交入口。
- 1.1.9 目标用户封禁、注销、资料隐藏或无权限查看时，页面展示不可访问提示。

### 1.2 顶部背景、头像与基础资料
- 1.2.1 个人资料页展示返回按钮，用户点击后返回上一页。
- 1.2.2 更多按钮有可用操作时，个人资料页右上角展示更多按钮。
- 1.2.3 更多按钮无可用操作时，个人资料页隐藏更多按钮。
- 1.2.4 用户未设置背景图时，个人资料页展示默认背景图。
- 1.2.5 用户未设置头像时，个人资料页展示默认头像。
- 1.2.6 用户昵称为空时，个人资料页展示默认昵称。
- 1.2.7 用户拥有炫彩昵称权益时，个人资料页展示炫彩昵称效果。
- 1.2.8 用户未设置个性签名时，个性签名区域按视觉方案隐藏或展示空状态。
- 1.2.9 用户年龄或性别未设置时，对应年龄标签或性别图标隐藏。

### 1.3 ID、靓号、国家与标签
- 1.3.1 普通用户无靓号时，个人资料页主展示位展示原始用户 ID。
- 1.3.2 用户有靓号时，个人资料页主展示位优先展示靓号。
- 1.3.3 用户有靓号时，页面同时展示靓号对应的标签背景样式。
- 1.3.4 不同靓号配置不同背景图时，页面展示各自服务端配置的背景图。
- 1.3.5 用户点击复制按钮时，系统复制当前主展示的用户 ID 或靓号。
- 1.3.6 用户 ID 数据缺失时，页面隐藏复制入口。
- 1.3.7 用户有国家信息时，页面展示国家或地区标识和文案。
- 1.3.8 用户无国家信息时，页面隐藏国家字段或展示占位。
- 1.3.9 国家修改成功后，个人资料页、用户卡片、搜索结果和榜单中的国家展示同步更新。

### 1.4 身份标签、公会标签与排序
- 1.4.1 用户身份为公会长时，个人资料页展示公会长标签。
- 1.4.2 用户身份为主播时，个人资料页展示主播身份标签。
- 1.4.3 用户加入公会时，个人资料页展示当前公会名称标签。
- 1.4.4 用户未加入公会时，个人资料页隐藏公会名称标签。
- 1.4.5 服务端返回自定义运营标签时，个人资料页展示对应标签。
- 1.4.6 标签存在优先级时，页面按优先级排序展示。
- 1.4.7 标签不存在优先级时，页面按标签获得时间降序展示。
- 1.4.8 标签样式为图片加文本且文本为空时，页面仍展示服务端配置的图片样式。
- 1.4.9 标签区不展示 VIP 等级、财富等级和魅力等级标签。

## 2. 个人资料页内容与社交
### 2.1 统计、切换与动态
- 2.1.1 Following 无数据时，个人资料页展示 0。
- 2.1.2 Fans 或 Follower 无数据时，个人资料页展示 0。
- 2.1.3 Visitor 无查看权限时，系统按访客权限规则拦截访问。
- 2.1.4 页面默认进入个人信息或入口指定状态。
- 2.1.5 用户点击“个人信息”时，页面展示我的房间、荣耀、公会、支持者和礼物墙预览。
- 2.1.6 用户点击“动态”时，页面切换到动态列表区。
- 2.1.7 动态列表展示发布时间、动态文本、动态图片、评论数和点赞数。
- 2.1.8 动态文本超长时，页面按动态规则折叠或截断。
- 2.1.9 动态图片失效时，页面展示占位图。

### 2.2 房间、公会与进入校验
- 2.2.1 用户当前在房间时，个人资料页顶部展示“正在房间”入口。
- 2.2.2 用户当前不在房间时，个人资料页隐藏“正在房间”入口。
- 2.2.3 用户有自己的房间时，个人信息页展示我的房间卡片。
- 2.2.4 用户没有自己的房间时，个人信息页隐藏我的房间区块。
- 2.2.5 用户点击正在房间入口且房间可进入时，系统进入该房间。
- 2.2.6 用户点击房间卡片且房间可进入时，系统进入该房间。
- 2.2.7 房间关闭、封禁、回收、已满或用户无权限时，系统展示不可进入提示。
- 2.2.8 用户有公会时，个人资料页展示公会封面、名称和公会 ID。
- 2.2.9 用户点击公会标签或公会卡片时，系统进入公会主页。

### 2.3 支持者与礼物墙
- 2.3.1 支持者区按历史累计送礼金额取 TOP3 用户展示。
- 2.3.2 幸运礼物按 10 金币等于 1 贡献值折算后参与支持者排序。
- 2.3.3 支持者不足 3 人时，页面按实际人数展示或展示空状态。
- 2.3.4 用户点击支持者头像、昵称或卡片时，系统进入支持者个人资料页。
- 2.3.5 支持者账号异常或资料不可访问时，系统展示不可访问提示。
- 2.3.6 礼物墙预览最多展示 6 个礼物。
- 2.3.7 礼物墙详情页展示完整礼物列表。
- 2.3.8 礼物数量为 0 或未点亮时，页面按灰态展示。
- 2.3.9 用户点击礼物墙标题、右侧箭头或更多入口时，系统进入礼物墙详情页。

### 2.4 关注、私信、拉黑与国家修改
- 2.4.1 访问他人资料且未关注时，页面展示关注按钮。
- 2.4.2 用户点击关注按钮成功后，页面刷新关注状态。
- 2.4.3 用户点击私信入口且双方聊天关系可用时，系统进入聊天页。
- 2.4.4 对方不可私信时，系统展示不可私信提示。
- 2.4.5 双方存在拉黑关系时，系统展示不可私信提示。
- 2.4.6 用户点击更多按钮后，页面展示举报、拉黑、分享等可用操作。
- 2.4.7 用户确认拉黑后，系统执行拉黑并刷新资料页状态。
- 2.4.8 用户具备房间管理权限时，拉黑确认流程展示“同时拉入房间黑名单”选项。
- 2.4.9 国家修改失败时，系统保留原国家且不消耗修改次数。

## 3. 直播间主页面与半屏消息
### 3.1 直播间主页面字段
- 3.1.1 用户进入直播间主页面后，系统加载房间信息、麦位状态、公屏消息和底部互动区。
- 3.1.2 房间信息区展示房主头像、昵称、性别、身高、ID 和玩法标签。
- 3.1.3 房间信息数据缺失时，页面按默认占位展示。
- 3.1.4 麦位区展示多麦位布局、当前上麦用户和空麦位。
- 3.1.5 空麦位展示默认占位。
- 3.1.6 房间实时人数按实时数据展示。
- 3.1.7 房间实时人数异常时，页面按 0 或最近有效值兜底。
- 3.1.8 公屏消息为空时，页面展示空状态或仅保留输入区。
- 3.1.9 无权限能力不在底部互动区展示。

### 3.2 直播间主页面交互
- 3.2.1 用户点击麦位上的用户时，系统打开对应半屏资料页。
- 3.2.2 用户点击房间榜入口时，系统进入房间榜相关页面。
- 3.2.3 房间榜无权限或无数据时，房间榜入口隐藏。
- 3.2.4 用户点击底部消息入口时，系统进入直播间半屏消息模块。
- 3.2.5 用户点击底部送礼入口时，系统按直播间送礼规则执行。
- 3.2.6 用户点击更多入口时，系统打开更多操作面板。
- 3.2.7 公屏中用户昵称展示口径与直播间其他用户信息展示口径一致。
- 3.2.8 公屏中用户标签展示口径与个人资料页标签口径一致。
- 3.2.9 房间榜入口数据来源与榜单模块的房间榜展示口径一致。

### 3.3 直播间半屏消息入口与列表
- 3.3.1 用户处于直播间主页面时，底部展示消息入口。
- 3.3.2 直播间消息入口无未读时，展示普通入口态。
- 3.3.3 直播间消息入口存在未读时，展示数字角标。
- 3.3.4 直播间消息入口未读数超过 99 时，展示 99+。
- 3.3.5 用户点击直播间消息入口后，页面从底部拉起半屏消息列表。
- 3.3.6 半屏消息面板打开后，直播间上半屏内容仍可见。
- 3.3.7 半屏消息页头部展示“消息”标题。
- 3.3.8 半屏消息无可展示会话时，页面展示空状态。
- 3.3.9 半屏消息面板拉起失败时，页面保留直播间原状态。

### 3.4 半屏消息会话、已读与返回
- 3.4.1 官方消息会话在半屏消息列表顶部展示。
- 3.4.2 官方消息图标加载失败时，页面展示默认官方标识。
- 3.4.3 官方消息摘要超长时，页面单行省略。
- 3.4.4 用户消息会话按最新消息时间倒序展示。
- 3.4.5 用户消息会话头像为空时，页面展示默认头像。
- 3.4.6 用户点击用户消息会话时，系统跳转与该用户的全屏聊天页。
- 3.4.7 用户点击官方或系统消息会话时，系统进入对应消息详情页。
- 3.4.8 单纯打开半屏消息列表时，不强制清除所有会话未读。
- 3.4.9 用户关闭半屏消息页后，页面回到原直播间主视图且不退出房间。

## 4. 直播间半屏资料页与房间权限
### 4.1 普通用户半屏资料页
- 4.1.1 普通用户点击麦位用户头像或昵称时，系统打开目标用户半屏资料页。
- 4.1.2 普通用户点击公屏用户头像或昵称时，系统打开目标用户半屏资料页。
- 4.1.3 目标用户已离开房间时，系统不打开半屏资料页并提示用户已离开房间。
- 4.1.4 目标用户已被房间黑名单拦截时，系统不展示可进入半屏资料页入口。
- 4.1.5 普通用户半屏资料页展示头像、昵称、ID 或靓号、国家、等级标签和身份标签。
- 4.1.6 用户佩戴头饰框时，半屏资料页展示对应头饰框动效。
- 4.1.7 普通用户查看他人时，页面展示关注、私聊、送礼、举报和拉黑按钮。
- 4.1.8 普通用户查看自己时，页面隐藏关注、私聊、送礼、举报和拉黑按钮。
- 4.1.9 普通用户半屏资料页不展示房间管理动作。

### 4.2 管理员半屏资料页
- 4.2.1 管理员查看普通用户时，系统打开管理员半屏资料页。
- 4.2.2 管理员半屏资料页基础资料展示口径与普通用户半屏资料页一致。
- 4.2.3 管理员具备禁言权限且目标允许被禁言时，页面展示禁言按钮。
- 4.2.4 目标用户当前处于禁言状态时，页面展示解除禁言按钮。
- 4.2.5 目标用户在麦上且允许闭麦时，页面展示闭麦按钮。
- 4.2.6 目标用户在麦上且处于闭麦状态时，页面展示开麦按钮。
- 4.2.7 目标用户在麦上且允许被下麦时，页面展示下麦按钮。
- 4.2.8 目标用户不在麦上且允许被邀请上麦时，页面展示邀请上麦按钮。
- 4.2.9 管理员查看房主时，页面隐藏越权管理动作。

### 4.3 房主半屏资料页
- 4.3.1 房主查看普通用户时，系统打开房主半屏资料页。
- 4.3.2 房主半屏资料页展示管理员可见范围内的管理操作。
- 4.3.3 目标用户不是管理员且允许被设置管理员时，页面展示设置管理员按钮。
- 4.3.4 目标用户已是管理员时，页面隐藏设置管理员按钮。
- 4.3.5 房主查看管理员时，页面展示取消管理员按钮。
- 4.3.6 目标用户不是管理员时，页面隐藏取消管理员按钮。
- 4.3.7 房主查看自己时，页面不展示对自己生效的管理动作。
- 4.3.8 房主设置管理员成功后，房间内目标用户管理员身份状态同步刷新。
- 4.3.9 房主取消管理员成功后，房间内目标用户管理员身份状态同步刷新。

### 4.4 防踢、黑名单与上下文保持
- 4.4.1 目标用户拥有防踢权益时，管理员不可执行请离房。
- 4.4.2 目标用户拥有防踢权益时，房主不可执行请离房。
- 4.4.3 用户被加入房间黑名单后，系统自动将该用户移出房间。
- 4.4.4 用户被加入房间黑名单后，系统禁止该用户再次进入对应房间。
- 4.4.5 用户被加入房间黑名单后，半屏资料页不再将该用户作为当前房间可操作目标返回。
- 4.4.6 半屏资料页打开时，不导致当前用户退出直播间。
- 4.4.7 半屏资料页关闭时，不清空直播间上下文。
- 4.4.8 半屏资料页拉取资料失败时，页面提示失败且保留直播间上下文。
- 4.4.9 半屏资料页执行管理动作失败时，系统提示失败且不错误变更目标状态。

## 5. 消息列表与官方系统消息
### 5.1 消息列表入口与会话展示
- 5.1.1 用户点击底部 Message 入口时，系统进入消息列表页。
- 5.1.2 用户从首页通知入口进入时，系统进入消息列表页。
- 5.1.3 消息列表页展示个人入口、页面标题、好友按钮和清除按钮。
- 5.1.4 用户未登录时点击个人入口，系统引导登录。
- 5.1.5 好友能力未开放时，好友按钮隐藏或提示暂不可用。
- 5.1.6 消息会话列表按最新消息时间倒序展示。
- 5.1.7 无最新消息且无固定入口配置的会话不展示。
- 5.1.8 会话头像或图标为空时，页面展示默认类型图标。
- 5.1.9 会话名称超长时，页面截断展示。

### 5.2 未读、清除与会话状态
- 5.2.1 每个消息会话独立统计未读数。
- 5.2.2 消息入口红点汇总所有会话未读数。
- 5.2.3 会话存在未读消息时，消息列表展示未读角标。
- 5.2.4 用户进入会话详情后，该会话未读按已读规则清除.
- 5.2.5 用户返回消息列表后，未读角标同步刷新。
- 5.2.6 清除按钮无可清除内容时，置灰或不展示。
- 5.2.7 清除未读成功后，当前消息页会话未读置为已读。
- 5.2.8 清除消息记录涉及删除时，系统展示二次确认弹窗。
- 5.2.9 清除失败时，系统提示失败原因且不改变原状态。

### 5.3 官方消息详情与URL跳转
- 5.3.1 用户点击官方消息会话后，系统进入官方消息详情页。
- 5.3.2 官方消息详情页按消息时间降序展示，最新消息在最上方。
- 5.3.3 官方消息时间按 YYMMDD:hhmmss 格式展示。
- 5.3.4 官方消息时间为空时，该条消息按兜底规则过滤或隐藏。
- 5.3.5 官方消息时间格式异常时，客户端按兜底规则格式化或隐藏该字段。
- 5.3.6 同时间官方消息按消息创建顺序或消息 ID 倒序兜底排序。
- 5.3.7 官方消息附带 URL 时，对应消息卡片展示 view 按钮。
- 5.3.8 官方消息未附带 URL 时，对应消息卡片不展示 view 按钮。
- 5.3.9 用户点击 view 后，系统跳转对应 URL 并携带当前登录信息。

### 5.4 系统消息分类与追溯
- 5.4.1 资料与内容审核消息点击后，可跳转对应资料或内容页面。
- 5.4.2 充值与提现消息点击后，可跳转钱包、充值、提现或明细页面。
- 5.4.3 薪资、公会与结算消息点击后，可跳转相关结算、公会或消息详情。

- 10.1.8 目标用户不可被邀请上麦时，系统不展示邀请入口或提示不可邀请。
- 10.1.9 邀请入口从半屏资料页触发时，直播间上下文保持不丢失。

### 10.2 邀请面板字段与选择
- 10.2.1 邀请上麦面板展示当前房间可邀请的指定麦位列表。
- 10.2.2 已占用麦位展示占用状态。
- 10.2.3 已占用麦位不可选择。
- 10.2.4 空闲麦位可选择。
- 10.2.5 用户选中空闲麦位后，该麦位高亮展示。
- 10.2.6 用户可从已选麦位切换到其他空闲麦位。
- 10.2.7 用户未选择麦位时，确认邀请按钮不可点击。
- 10.2.8 用户选择空闲麦位后，确认邀请按钮可点击。
- 10.2.9 用户点击取消按钮后，邀请面板关闭且不发起邀请。

### 10.3 邀请发送、接受与麦位校验
- 10.3.1 发起者选择麦位并点击确认后，系统向目标用户发起上麦邀请。
- 10.3.2 邀请发出后，系统记录目标用户、目标麦位、发起者、发起时间和邀请状态。
- 10.3.3 邀请发送中时，发起方展示邀请已发送状态。
- 10.3.4 目标用户接受邀请前，系统不执行实际上麦。
- 10.3.5 目标用户接受邀请时，系统再次校验目标麦位是否空闲。
- 10.3.6 目标麦位仍空闲时，系统将目标用户上到指定麦位。
- 10.3.7 上麦成功后，系统同步直播间麦位状态。
- 10.3.8 目标麦位已被占用时，系统取消本次上麦。
- 10.3.9 目标麦位已被占用时，系统 Toast 提示“该麦位已有用户上麦”。

### 10.4 拒绝、超时与并发异常
- 10.4.1 目标用户拒绝邀请时，本次邀请失效且不执行上麦。
- 10.4.2 目标用户拒绝邀请后，发起方收到邀请失败提示。
- 10.4.3 邀请超时未处理时，本次邀请失效且不执行上麦。
- 10.4.4 邀请超时后，发起方收到邀请已失效提示。
- 10.4.5 邀请失败时，系统按失败原因提示发起方。
- 10.4.6 邀请拒绝、超时、成功和失败均记录结果。
- 10.4.7 邀请结果同步给发起方。
- 10.4.8 邀请结果同步给目标用户。
- 10.4.9 目标接受时麦位被其他用户抢占后，不允许强制顶替已上麦用户。

## 12. 身份权限、边界与安全
### 12.1 角色权限绕过
- 12.1.1 普通用户直接调用禁言接口时，服务端拒绝执行。
- 12.1.2 普通用户直接调用闭麦接口时，服务端拒绝执行。
- 12.1.3 普通用户直接调用下麦接口时，服务端拒绝执行。
- 12.1.4 普通用户直接调用请离房接口时，服务端拒绝执行。
- 12.1.5 管理员直接调用设置管理员接口时，服务端拒绝执行。
- 12.1.6 管理员直接调用取消管理员接口时，服务端拒绝执行。
- 12.1.7 管理员直接对房主执行管理动作时，服务端拒绝执行。
- 12.1.8 无邀请权限用户直接调用邀请上麦接口时，服务端拒绝执行。
- 12.1.9 目标具备防踢权益时，直接调用请离房接口仍被服务端拒绝。

### 12.2 数据边界
- 12.2.1 支持者累计送礼金额为 0 时，不应错误排在有贡献用户之前。
- 12.2.2 幸运礼物金币数为 0 时，折算贡献值为 0。
- 12.2.3 礼物墙礼物数量为空时，详情页展示 0。
- 12.2.4 礼物墙礼物数量为 0 时，礼物按灰态展示。
- 12.2.5 未读消息数为 0 时，不展示未读角标。
- 12.2.6 未读消息数等于 99 时，角标展示 99。
- 12.2.7 未读消息数大于 99 时，角标展示 99+。
- 12.2.8 商品价格为空时，商品不可购买。
- 12.2.9 物料剩余天数小于或等于 0 时，系统按过期物料处理。

### 12.3 状态流转与终态
- 12.3.1 拉黑成功后，私信入口按拉黑规则限制。
- 12.3.2 拉黑成功且同步加入房间黑名单后，目标用户无法进入对应房间。
- 12.3.3 进入消息详情后，会话未读状态从未读流转为已读。
- 12.3.4 清除未读成功后，会话未读状态保持已读。
- 12.3.5 商品购买成功后，购买结果不可通过返回按钮撤销。
- 12.3.6 商品发放成功后，背包物料状态从未拥有流转为已拥有。
- 12.3.7 佩戴成功后，物料状态从未使用流转为使用中。
- 12.3.8 取消佩戴成功后，物料状态从使用中流转为未使用。
- 12.3.9 邀请上麦拒绝或超时后，该邀请终态不可再次被接受。

### 12.4 并发与幂等
- 12.4.1 用户连续点击关注按钮时，系统只生成一次有效关注结果。
- 12.4.2 用户连续点击私信发送按钮时，系统不重复发送同一条消息。
- 12.4.3 用户连续点击购买确认按钮时，系统只扣费一次。
- 12.4.4 用户连续点击立即佩戴按钮时，系统只保留一次佩戴结果。
- 12.4.5 用户连续点击取消佩戴按钮时，系统只保留一次取消结果。
- 12.4.6 管理员连续发起同一目标同一麦位邀请时，系统按邀请状态限制重复邀请。
- 12.4.7 目标用户接受邀请时麦位状态已变化，系统按最新麦位状态校验。
- 12.4.8 官方消息 URL 重复点击时，系统不重复创建异常登录态。
- 12.4.9 消息清除操作重复点击时，系统不重复删除或重复变更消息状态。

## 14. 中断回退、配置变更与待确认项
### 14.1 网络、登录态与返回
- 14.1.1 个人资料页加载网络异常时，页面展示错误提示并允许重试。
- 14.1.2 半屏消息列表加载网络异常时，页面展示错误提示并允许重试。
- 14.1.3 聊天页历史消息加载网络异常时，页面展示错误提示并允许重试。
- 14.1.4 背包分类切换网络异常时，页面保留原分类并提示失败。
- 14.1.5 商城分类切换网络异常时，页面保留原分类或提示失败。
- 14.1.6 等级页 Tab 切换网络异常时，页面保留原状态并提示失败。
- 14.1.7 用户 token 过期时发送消息，系统拒绝发送并引导重新登录。
- 14.1.8 用户 token 过期时购买商品，系统拒绝扣费并引导重新登录。
- 14.1.9 用户 token 过期时执行房间管理动作，系统拒绝执行并引导重新登录。

### 14.2 配置动态化
- 14.2.1 靓号背景图配置变更后，个人资料页按最新服务端配置展示。
- 14.2.2 标签样式配置变更后，个人资料页按最新服务端配置展示。
- 14.2.3 官方消息和小助手消息置顶配置变更后，消息列表排序按新配置展示。
- 14.2.4 系统消息业务跳转配置变更后，点击消息进入最新配置目标。
- 14.2.5 背包分类配置新增后，背包页展示新增分类。
- 14.2.6 商城分类配置新增后，商城页展示新增分类。
- 14.2.7 商品下架配置生效后，商城不允许继续购买该商品。
- 14.2.8 等级区间图标配置变更后，等级页展示最新区间图标。
- 14.2.9 房间管理权限配置变更后，半屏资料页管理按钮按新权限返回。

### 14.3 回退与失败不污染数据
- 14.3.1 用户关闭拉黑确认弹窗时，系统不拉黑目标用户。
- 14.3.2 用户关闭购买确认弹窗时，系统不扣费且不发放商品。
- 14.3.3 用户关闭购买成功弹窗时，已购买商品仍保留在背包。
- 14.3.4 用户关闭邀请上麦面板时，系统不发起邀请。
- 14.3.5 图片消息发送失败时，系统不生成成功图片消息。
- 14.3.6 语音消息发送失败时，系统不生成成功语音消息。
- 14.3.7 礼物消息发送失败时，系统不扣费或按失败补偿规则恢复资产。
- 14.3.8 佩戴失败时，个人展示状态不被错误更新。
- 14.3.9 等级数据异常兜底展示时，不写回覆盖真实等级数据。

### 14.4 阻塞确认项与回归门禁
- 14.4.1 待确认：个人资料页已关注后的按钮是否支持取消关注，确认后回归关注状态切换。
- 14.4.2 待确认：礼物墙详情中单个礼物点击是否开放礼物详情，确认后回归礼物点击链路。
- 14.4.3 待确认：清除按钮范围是清未读、清空列表消息还是批量管理，确认后回归清除流程。
- 14.4.4 待确认：官方消息 view 按钮最终文案是否按消息类型变化，确认后回归多语言文案。
- 14.4.5 待确认：图片和语音发送的财富等级门槛具体等级，确认后回归权限限制弹窗。
- 14.4.6 待确认：聊天房间状态提示关闭后的持久化策略，确认后回归本次会话和跨会话展示。
- 14.4.7 待确认：已拥有商品再次购买是否叠加时长，确认后回归商城购买与背包有效期。
- 14.4.8 待确认：同一分类物料是否全部互斥，确认后回归佩戴替换和共存规则。
- 14.4.9 待确认：UI 优化参考图与正式 PRD 视觉冲突时的具体验收范围，确认后回归相关页面样式。
