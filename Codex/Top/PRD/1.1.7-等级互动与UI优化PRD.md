# 一、等级页面模块

## 1.1 页面定位 / 功能说明

等级页面模块用于展示财富等级（Wealth）和魅力等级（Charm）两套等级体系。页面由 Tab、等级信息卡片、进度条和等级区间图标表组成，核心是让用户快速看到当前等级、升级差值和各等级段对应图标。

该页面的核心目标：

1. 展示当前财富等级 / 魅力等级及升级差值。
2. 展示当前进度百分比和进度条。
3. 支持 Wealth / Charm 双 Tab 切换。
4. 展示等级区间与图标映射关系。

| 原型 | 说明 |

## 1.3 前置条件

| 场景 | 前置条件 | 处理方式 |
|---|---|---|
| 进入等级页面 | 用户从个人资料页、等级标签、榜单标签或其他等级入口进入 | 默认展示入口指定的等级类型；未指定时默认展示 Wealth |
| 查看财富等级 | 用户点击 Wealth Tab | 展示财富等级页 |
| 查看魅力等级 | 用户点击 Charm Tab | 展示魅力等级页 |
| 等级数据为空 | 系统未返回等级信息 | 展示 LV0、0% 和距离下一等级所需经验文案 |
| 网络异常 | 等级数据加载失败 | 展示错误提示并允许重试 |

## 1.4 页面结构

等级页面由以下区块组成：

1. 顶部导航区
2. Wealth / Charm Tab 切换区
3. 用户等级信息卡片区
4. 进度条区
5. 等级区间图标表格区
6. 空状态 / 异常状态区

## 1.5 页面字段定义

### 1.5.1 顶部导航与 Tab 切换区

| 字段 / 元素 | 展示规则 | 交互规则 | 异常 / 空值处理 |
|---|---|---|---|
| 返回按钮 | 展示在左上角 | 点击返回上一页 | 无 |
| Wealth Tab | 展示财富等级入口 | 点击切换到财富等级页 | 加载失败时保留当前页并提示失败 |
| Charm Tab | 展示魅力等级入口 | 点击切换到魅力等级页 | 加载失败时保留当前页并提示失败 |
| 选中态 | 当前等级类型文字高亮，并展示底部短线指示器 | 切换后刷新等级卡片、经验文案、进度和图标表格 | 无 |

### 1.5.2 用户等级信息卡片区

| 字段 / 元素 | 展示规则 | 交互规则 | 异常 / 空值处理 |
|---|---|---|---|
| 用户头像 | 展示当前用户头像 | 点击是否进入个人资料页 | 头像为空时展示默认头像 |
| 用户昵称 | 展示当前用户昵称，原型示例为 `Weo` | 仅展示 | 昵称为空时展示默认昵称 |
| 升级经验文案 | 展示距离下一等级所需经验，原型示例为 `Need 24000 exp to LV1`、`Need 28000 exp to LV1` | 仅展示 | 满级时展示已达最高等级或满级文案 |
| 当前等级 | 展示当前等级，原型示例为 `LV0` | 仅展示 | 无等级数据时展示 LV0 |
| 当前进度百分比 | 展示当前等级进度，原型示例为 `0%` | 仅展示 | 无数据时展示 0% |
| 等级进度条 | 按当前进度展示填充比例 | 仅展示 | 进度异常时按 0% 兜底 |
| 主题背景 | Wealth 使用金棕 / 黑金主题；Charm 使用紫粉 / 魅力主题 | 随 Tab 切换同步变化 | 背景加载失败时展示默认背景 |

### 1.5.3 等级区间图标表格区

| 字段 / 元素 | 展示规则 | 交互规则 | 异常 / 空值处理 |
|---|---|---|---|
| 表头 Level | 展示等级区间列表表头 | 仅展示 | 无 |
| 表头 Icon | 展示图标列表表头 | 仅展示 | 无 |
| 等级区间 | 按固定区间展示等级段 | 仅展示 | 无数据时隐藏该行 |
| 区间图标 | 展示该等级区间对应图标 | 仅展示 | 图标缺失时展示默认占位图标 |
| 图标数字标识 | 图标上展示对应区间编号，原型示例为 `1 / 10 / 20 / 30 / ... / 100` | 仅展示 | 无数字时展示默认编号样式 |

## 1.6 统计 / 计算口径

### 1.6.1 等级类型口径

| 等级类型 | 展示名称 | 经验含义 | 展示主题 |
|---|---|---|---|
| 财富等级 | Wealth | 用户财富成长相关经验 | 金棕 / 黑金主题 |
| 魅力等级 | Charm | 用户魅力成长相关经验 | 紫粉 / 魅力主题 |

### 1.6.2 升级经验与进度口径

| 规则项 | 口径 |
|---|---|
| 当前等级 | 按用户当前财富等级或魅力等级展示 |
| 距离下一等级所需经验值 | 下一等级所需最低经验值 - 当前经验值 |
| 进度百分比 | (当前经验 - 当前等级起始经验) ÷ (下一等级起始经验 - 当前等级起始经验) |
| 进度条展示 | 按当前进度百分比填充 |
| 进度兜底 | 无数据或异常时展示 0% |
| 满级处理 | 达到最高等级时，不再展示下一等级差值，改为满级文案 |

### 1.6.3 等级区间口径

| 区间 | 图标编号 |
|---|---|
| 1-9 | 1 |
| 10-19 | 10 |
| 20-29 | 20 |
| 30-39 | 30 |
| 40-49 | 40 |
| 50-59 | 50 |
| 60-69 | 60 |
| 70-79 | 70 |
| 80-89 | 80 |
| 90-99 | 90 |
| 100 | 100 |

### 1.6.4 等级标签规则口径

| 规则项 | 口径 |
|---|---|
| 财富等级标签规则 | 可定义用户在指定等级范围显示某个财富等级标签，例如 LV1-9 显示财富等级 1 标签 |
| 魅力等级标签规则 | 可定义用户在指定等级范围显示某个魅力等级标签，例如 LV1-9 显示魅力等级 1 标签 |
| 标签联动场景 | 个人资料页、聊天页资料卡、榜单、房间公屏等展示财富等级 / 魅力等级标签 |

## 1.7 交互逻辑

### 1.7.1 进入等级页面

1. 用户从个人资料页、等级标签、榜单标签或其他入口进入等级页面。
2. 系统按入口展示对应等级类型；未指定时默认展示 Wealth。
3. 页面加载头像、昵称、当前等级、升级差值、进度和等级区间图标表格。

### 1.7.2 切换 Wealth / Charm

1. 点击 Wealth 或 Charm。
2. 页面切换 Tab 选中态并刷新对应数据。
3. 卡片主题、经验文案、当前等级、进度条和图标表格同步更新。
4. 加载失败时保留原状态并提示失败。

### 1.7.3 查看等级区间图标

1. 页面展示从 `1-9` 到 `100` 的等级区间列表。
2. 每个区间右侧展示对应图标和编号。
3. 1.0 当前按静态对照展示处理，不要求点击进入详情页。

## 1.8 状态定义

| 状态 | 触发条件 | 页面表现 | 用户可操作 |
|---|---|---|---|
| 加载中 | 进入页面或切换等级类型 | 展示加载态 | 等待加载完成 |
| 财富等级选中 | 当前 Tab 为 Wealth | 展示财富主题卡片、财富经验文案和财富图标表格 | 可切换 Charm |
| 魅力等级选中 | 当前 Tab 为 Charm | 展示魅力主题卡片、魅力经验文案和魅力图标表格 | 可切换 Wealth |
| LV0 初始状态 | 用户当前等级为 LV0 | 展示 LV0、0% 和距离下一等级所需经验文案 | 可切换等级类型 |
| 正常进度状态 | 用户已有等级经验 | 展示当前进度百分比和进度条 | 可切换等级类型 |
| 满级状态 | 用户达到最高等级 | 展示满级文案 | 可查看图标表格 |
| 网络异常 | 等级数据加载失败 | 展示错误提示 | 可重试 |

## 1.9 系统后台核心逻辑

1. 系统需要分别维护用户财富等级和魅力等级，两套等级体系独立展示。
2. 系统返回当前用户的财富等级、魅力等级、当前经验值、下一等级所需经验值和进度百分比。
3. 财富等级和魅力等级的经验来源、升级条件和图标素材应分别配置，不能混用。
4. 页面切换 Wealth / Charm 时，系统返回对应等级类型下的当前等级、经验文案、进度和等级区间图标表格配置。
5. 等级区间图标配置需要包含等级区间、区间编号、图标素材和主题类型。
6. 达到最高等级时，系统应返回满级状态，页面不再展示下一等级差值。
7. 等级标签规则需要支持按区间映射不同等级标签，并同步用于个人资料页、聊天页、榜单、房间公屏等场景。
8. 等级数据异常时，页面应按 LV0 和 0% 进度兜底，但不得覆盖用户真实等级数据。

## 1.10 异常与测试关注点

| 场景 | 测试关注点 | 预期结果 |
|---|---|---|
| 进入等级页 | 是否展示头像、昵称、等级、经验文案、进度条和图标表格 | 页面完整展示 |
| Wealth 默认展示 | 无入口指定时默认类型是否正确 | 默认展示财富等级页 |
| 切换 Charm | 是否刷新为魅力等级数据 | 主题、经验文案、等级、进度和图标表格均更新 |
| 切换失败 | 是否覆盖原数据 | 保留原页面并提示失败 |
| LV0 用户 | 是否正确展示初始状态 | 展示 LV0、0%、距离下一等级所需经验文案 |
| 经验进度 | 百分比和进度条是否计算正确 | 进度条与百分比一致 |
| 满级用户 | 是否仍展示下一等级差值 | 展示满级文案，不展示错误差值 |
| 等级区间图标表格 | 是否完整展示 1-9 至 100 区间 | 区间完整、图标编号正确 |
| 财富 / 魅力主题差异 | 是否正确展示两套视觉主题和图标 | Wealth 为金棕主题，Charm 为紫粉主题 |
| 网络异常 | 等级数据加载失败 | 展示错误提示并可重试 |

# 二、邀请用户上麦模块

## 2.1 页面定位 / 功能说明

邀请用户上麦模块用于房主或管理员在直播间内选择指定麦位，对目标用户发起上麦邀请。该能力独立于直播间半屏资料页模块，半屏资料页仅承接邀请入口展示，邀请链路、邀请结果、麦位占用校验在本模块中统一定义。

## 2.2 对应原型

![邀请用户上麦原型](1.0汇总原型图/直播间-邀请用户上麦.jpg)

## 2.3 前置条件

| 场景 | 前置条件 | 处理方式 |
|---|---|---|
| 房主发起邀请 | 当前用户为房主，目标用户可被邀请上麦，目标用户当前不在麦上 | 打开邀请上麦面板，选择指定麦位 |
| 管理员发起邀请 | 当前用户为管理员，具备邀请上麦权限，目标用户当前不在麦上 | 打开邀请上麦面板，选择指定麦位 |
| 无可用麦位 | 当前房间无空闲麦位 | 不允许发起邀请，提示当前无可用麦位 |
| 目标用户已在麦上 | 目标用户当前已在任一麦位 | 不展示邀请上麦入口 |

## 2.4 页面字段定义

| 字段 / 元素 | 展示规则 | 交互规则 | 异常 / 空值处理 |
|---|---|---|---|
| 麦位列表 | 展示当前房间可邀请的指定麦位 | 点击选择目标麦位 | 已占用麦位展示占用状态，不可选 |
| 当前选中麦位 | 用户选中某个空闲麦位后高亮展示 | 可切换其他空闲麦位 | 未选择时确认按钮不可用 |
| 取消按钮 | 固定展示 | 点击关闭邀请上麦面板 | 无 |
| 确认邀请按钮 | 选择空闲麦位后可点击 | 点击向目标用户发起上麦邀请 | 未选麦位时不可点击 |
| 邀请结果提示 | 邀请发出后根据结果展示 | 成功、拒绝、超时、失败分别提示 | 失败时按失败原因提示 |

## 2.5 交互逻辑

1. 房主或管理员在直播间内对目标点击“邀请上麦”。
2. 系统打开邀请上麦面板，展示当前可选麦位列表。
3. 发起者选择某个指定麦位后，点击确认邀请。
4. 系统向目标用户发起上麦邀请，目标用户需主动接受后才允许真正上麦。
5. 若目标用户拒绝邀请或邀请超时，本次邀请失效，不执行上麦。
6. 若目标用户接受邀请，系统在真正执行上麦前再次校验目标麦位是否仍为空闲。
7. 若目标麦位已被其他用户占用，则取消本次上麦，并 Toast 提示：`该麦位已有用户上麦`。
8. 若目标麦位仍为空闲，则将目标用户上到该指定麦位。

## 2.6 状态定义

| 状态 | 触发条件 | 页面表现 | 用户可操作 |
|---|---|---|---|
| 默认状态 | 打开邀请上麦面板 | 展示可选麦位列表 | 可选择麦位或取消 |
| 未选麦位状态 | 用户未选择任何麦位 | 确认邀请按钮置灰 | 可继续选择麦位 |
| 已选麦位状态 | 用户已选择某个空闲麦位 | 选中麦位高亮，确认邀请按钮可点击 | 可确认邀请或切换麦位 |
| 邀请发送中状态 | 发起者确认邀请后 | 展示邀请已发送状态 | 等待目标用户处理 |
| 邀请被拒绝状态 | 目标用户拒绝邀请 | 提示邀请失败 | 可重新发起邀请 |
| 邀请超时状态 | 目标用户超时未处理 | 提示邀请已失效 | 可重新发起邀请 |
| 麦位占用失败状态 | 目标用户接受时目标麦位已被占用 | Toast：`该麦位已有用户上麦` | 可重新选择麦位发起邀请 |
| 邀请成功状态 | 目标用户接受且目标麦位空闲 | 目标用户成功上麦 | 结束当前邀请流程 |

## 2.7 系统后台核心逻辑

1. 系统根据当前房间实时麦位状态，返回可供邀请的空闲麦位列表。
2. 系统校验当前发起者是否具备邀请用户上麦权限。
3. 系统校验目标用户当前是否已在麦上；已在麦上时不得继续发起邀请。
4. 系统需要在邀请发出后记录邀请中的目标用户、目标麦位、发起者、发起时间和邀请状态。
5. 系统需要在目标用户接受邀请时再次校验目标麦位是否仍为空闲。
6. 若目标麦位已被占用，则取消本次上麦，不允许强制顶替，并返回 Toast：`该麦位已有用户上麦`。
7. 若目标麦位仍为空闲，则将目标用户上到该指定麦位，并同步直播间麦位状态。
8. 邀请拒绝、邀请超时、邀请成功、邀请失败都需要记录结果，并同步给发起方与目标用户。

## 2.8 异常与测试关注点

| 场景 | 测试关注点 | 预期结果 |
|---|---|---|
| 发起邀请时有空闲麦位 | 是否可正常选择指定麦位并发起邀请 | 可成功发起邀请 |
| 发起邀请时无空闲麦位 | 是否禁止发起邀请 | 提示当前无可用麦位 |
| 目标用户拒绝邀请 | 是否不执行上麦 | 邀请失效，目标用户不上麦 |
| 目标用户邀请超时 | 是否不执行上麦 | 邀请失效，目标用户不上麦 |
| 目标用户接受时麦位被占用 | 是否取消本次上麦并提示正确文案 | Toast：`该麦位已有用户上麦` |
| 目标用户接受时麦位仍空闲 | 是否成功上到指定麦位 | 用户成功上麦 |
