## 1. 登录模块
### 1.1 登录首页与第三方入口
- 1.1.1 未登录用户首次打开 App 时，系统展示登录首页。
- 1.1.2 登录首页加载成功时，页面展示 Logo、品牌名、礼包提示、第三方登录按钮和协议说明。
- 1.1.3 Logo 资源加载失败时，页面展示默认 Logo。
- 1.1.4 无礼包提示配置时，登录首页隐藏礼包提示区域。
- 1.1.5 支持 Google 登录的环境中，登录首页展示 Google 登录按钮。
- 1.1.6 用户点击 Google 登录按钮时，系统拉起 Google 授权流程。
- 1.1.7 iOS 或支持 Apple 登录的设备中，登录首页展示 Apple 登录按钮。
- 1.1.8 非 Apple 登录支持端中，登录首页不展示 Apple 登录按钮。
- 1.1.9 用户点击 User Agreement 或 Privacy Policy 时，系统打开对应协议页面。

### 1.2 手机号密码登录
- 1.2.1 用户点击手机号登录入口后，页面进入手机号密码登录页。
- 1.2.2 手机号登录页展示返回按钮、页面标题、国家区号、手机号输入框、密码输入框和登录按钮。
- 1.2.3 国家区号未获取成功时，页面展示默认区号。
- 1.2.4 手机号输入框为空时，登录按钮不可提交。
- 1.2.5 手机号输入框有内容时，页面展示清空按钮。
- 1.2.6 用户点击清空按钮后，手机号输入框内容被清空。
- 1.2.7 密码输入框为空时，登录按钮不可提交。
- 1.2.8 手机号格式不符合对应国家规则时，系统提示手机号格式错误。
- 1.2.9 手机号和密码满足基本校验时，登录按钮变为可点击状态。

### 1.3 邮箱密码登录
- 1.3.1 用户点击邮箱登录入口后，页面进入邮箱密码登录页。
- 1.3.2 邮箱登录页展示返回按钮、页面标题、邮箱输入框、密码输入框和 LOGIN 按钮。
- 1.3.3 邮箱输入框为空时，LOGIN 按钮不可提交。
- 1.3.4 邮箱格式错误时，LOGIN 按钮不可提交或展示格式错误提示。
- 1.3.5 密码输入框为空时，LOGIN 按钮不可提交。
- 1.3.6 邮箱格式正确且密码不为空时，LOGIN 按钮变为可点击状态。
- 1.3.7 邮箱密码登录失败时，页面展示账号或密码错误提示。
- 1.3.8 邮箱密码登录失败后，页面保留邮箱输入内容。
- 1.3.9 邮箱密码登录成功后，系统写入登录状态并进入首页或原目标页面。

### 1.4 登录状态、拦截与异常
- 1.4.1 第三方授权取消时，用户停留在当前登录页且不进入 App。
- 1.4.2 第三方授权失败时，页面展示授权失败原因。
- 1.4.3 登录中状态下，登录按钮展示加载态或锁定态。
- 1.4.4 登录中重复点击提交按钮时，系统只发起一次登录请求。
- 1.4.5 登录状态失效后重新登录成功时，系统回到原目标页面。
- 1.4.6 中国大陆 IP 命中时，手机号登录被拦截且不继续校验账号密码。
- 1.4.7 中国大陆 IP 命中时，邮箱登录被拦截且不继续校验账号密码。
- 1.4.8 中国大陆 IP 命中时，第三方登录被拦截且不写入登录态。
- 1.4.9 永久封禁或临时封禁账号登录时，系统拦截进入 App 并展示对应封禁提示。

## 2. 注册资料补全模块
### 2.1 进入资料补全页与基础字段
- 2.1.1 新用户完成注册且 IP 不属于中国大陆时，系统展示 Complete your profile 页面。
- 2.1.2 第三方首次授权用户资料不完整时，系统进入资料补全页。
- 2.1.3 中国大陆 IP 注册命中时，系统拦截注册流程且不创建账号或不进入资料补全页。
- 2.1.4 资料补全页展示顶部返回按钮和页面标题。
- 2.1.5 用户点击返回按钮时，页面返回上一步注册或登录流程。
- 2.1.6 返回会丢失已填内容时，系统按产品策略提示或保留草稿。
- 2.1.7 资料补全页展示头像、昵称、性别、生日、国家和 Confirm 按钮。
- 2.1.8 Confirm 按钮在必填资料不满足校验时不可提交或提示完善资料。
- 2.1.9 资料保存失败时，页面保留用户已填写内容。

### 2.2 头像、昵称与性别
- 2.2.1 用户进入资料补全页时，系统展示默认头像。
- 2.2.2 用户点击头像或编辑图标时，系统打开头像选择底部弹层。
- 2.2.3 用户选择默认头像后，头像预览更新为所选默认头像。
- 2.2.4 用户选择 Photo album 时，系统请求相册权限。
- 2.2.5 用户拒绝相册权限时，系统提示权限不足且不崩溃。
- 2.2.6 用户选择 Take photos 时，系统请求相机权限。
- 2.2.7 用户拒绝相机权限时，系统提示权限不足且不崩溃。
- 2.2.8 用户点击随机昵称按钮时，系统生成 1 个未重复的新昵称。
- 2.2.9 用户选择男性或女性后，对应性别选项高亮且另一项取消高亮。

### 2.3 生日、国家与默认策略
- 2.3.1 用户点击生日字段时，系统打开日期选择器。
- 2.3.2 用户选择不满足年龄策略的生日时，页面展示年龄限制提示。
- 2.3.3 用户定位或 IP 识别成功为海湾国家时，国家字段自动回填对应海湾国家。
- 2.3.4 用户定位或 IP 识别失败时，系统随机选择 1 个海湾国家作为默认国籍。
- 2.3.5 国家列表由服务端返回时，客户端按服务端排序展示。
- 2.3.6 国家列表由服务端删除某国家时，客户端不再展示该国家。
- 2.3.7 用户输入国家关键词时，国家列表按关键词筛选。
- 2.3.8 国家搜索无结果时，页面展示空状态。
- 2.3.9 国家文案在中文、英文、阿拉伯语环境下按服务端多语言配置展示。

### 2.4 提交校验与异常
- 2.4.1 昵称为空时，Confirm 按钮不可提交或提示请输入昵称。
- 2.4.2 昵称重复时，系统提示“昵称已存在，请重新设置”。
- 2.4.3 昵称命中敏感词时，系统提示内容不合法。
- 2.4.4 昵称包含不允许特殊字符时，系统提示内容不合法。
- 2.4.5 性别未选择时，Confirm 按钮不可提交或提示完善资料。
- 2.4.6 头像上传成功且资料提交成功时，系统保存头像素材。
- 2.4.7 提交中状态下，Confirm 按钮不可重复点击。
- 2.4.8 提交成功后，系统进入首页或下一步注册完成流程。
- 2.4.9 提交失败后，用户可修改字段并重新提交。

## 3. 设置、账号绑定与密码模块
### 3.1 设置主页
- 3.1.1 已登录用户进入设置页时，页面展示 Settings 标题。
- 3.1.2 设置页展示 Account Settings 入口。
- 3.1.3 设置页展示 Change Password 入口。
- 3.1.4 设置页展示 Privacy Settings 入口。
- 3.1.5 设置页展示 Logout 入口。
- 3.1.6 设置页展示 Privacy Policy 和 User Agreement 入口。
- 3.1.7 设置页展示当前 App 版本号。
- 3.1.8 用户点击检查更新且无新版本时，系统提示“已是最新版本”。
- 3.1.9 用户点击检查更新且有新版本时，系统引导前往应用商店更新。

### 3.2 账号管理页与手机号绑定
- 3.2.1 用户从设置页点击 Account Settings 后进入账号管理页。
- 3.2.2 账号管理页展示手机号绑定状态。
- 3.2.3 用户已绑定手机号时，页面展示当前手机号。
- 3.2.4 用户未绑定手机号时，页面展示蓝色 Not Set 和右侧箭头。
- 3.2.5 用户点击手机号入口后进入手机号绑定页。
- 3.2.6 手机号绑定页展示区号选择器、手机号输入框、再次输入手机号输入框和确认绑定按钮。
- 3.2.7 用户两次输入手机号不一致时，确认绑定按钮不可点击或展示不一致提示。
- 3.2.8 用户输入手机号格式错误时，系统提示正确格式。
- 3.2.9 用户输入合法且一致的手机号后，系统提交绑定请求。

### 3.3 邮箱绑定与验证码
- 3.3.1 账号管理页展示邮箱绑定状态。
- 3.3.2 用户已有邮箱时，页面展示当前邮箱。
- 3.3.3 用户无邮箱时，页面展示蓝色 Not Set 和右侧箭头。
- 3.3.4 用户点击邮箱入口后进入邮箱绑定页。
- 3.3.5 邮箱绑定页展示邮箱输入框、验证码输入框、发送按钮和确认绑定按钮。
- 3.3.6 用户输入邮箱格式错误时，确认绑定按钮不可点击或展示格式错误提示。
- 3.3.7 用户点击发送按钮后，系统发送验证码到邮箱。
- 3.3.8 验证码发送后 60 秒倒计时期间，发送按钮不可再次点击。
- 3.3.9 用户输入错误验证码时，系统提示验证码错误且不完成绑定。

### 3.4 修改或设置密码
- 3.4.1 已设置密码用户进入修改密码页时，页面展示原始密码、新密码和确认新密码输入框。
- 3.4.2 未设置密码用户进入修改密码页时，页面隐藏原始密码输入框。
- 3.4.3 密码输入框默认以不可见形式展示密码。
- 3.4.4 用户切换密码显隐时，输入内容保持不变。
- 3.4.5 输入不完整时，确认修改按钮置灰。
- 3.4.6 已设置密码用户提交错误原始密码时，系统提示 Original password error。
- 3.4.7 两次新密码不一致时，系统提示 New password and confirmation do not match。
- 3.4.8 未设置密码用户首次设置成功后，系统将账号更新为已设置密码状态。
- 3.4.9 密码修改成功后，系统清空所有密码输入内容并提示成功。

## 4. 编辑资料、隐私与注销模块
### 4.1 编辑个人资料页
- 4.1.1 用户从个人中心设置进入编辑资料页时，页面回填当前头像、昵称、性别、生日、国家和个性签名。
- 4.1.2 用户无头像时，页面展示默认头像。
- 4.1.3 用户无昵称时，页面展示系统默认昵称或占位。
- 4.1.4 性别字段仅展示，不允许用户修改。
- 4.1.5 语音签名字段不在编辑资料页展示。
- 4.1.6 用户点击国家字段且未达到修改限制时，进入选择国家页面。
- 4.1.7 国家选择范围覆盖中东地区、欧美地区国家和印度。
- 4.1.8 用户达到国家修改次数限制后点击国家字段，系统提示“每个账号仅支持修改1次国家”。
- 4.1.9 保存成功后，个人资料页和直播间半屏资料页同步刷新最新资料。

### 4.2 隐私设置与榜单匿名入口
- 4.2.1 用户从设置主页进入 Privacy Settings 后，页面展示隐私设置页。
- 4.2.2 隐私设置页展示 Rank Invisible 入口。
- 4.2.3 隐私设置页展示 Rank Invisible 当前开启或关闭状态。
- 4.2.4 隐私设置页展示 Blacklist 入口。
- 4.2.5 榜单匿名能力未开放时，Rank Invisible 入口置灰或隐藏。
- 4.2.6 榜单匿名状态缺失时，页面按关闭状态处理。
- 4.2.7 用户具备榜单匿名权益时，可切换榜单匿名状态。
- 4.2.8 用户不具备榜单匿名权益时，切换不生效并展示权益说明。
- 4.2.9 用户切换榜单匿名状态后，榜单展示口径实时更新。

### 4.3 注销账号流程
- 4.3.1 用户点击 Delete Account 后，页面弹出注销二次确认弹窗。
- 4.3.2 注销弹窗展示剩余资产、未提现余额、公会或工资风险说明。
- 4.3.3 注销弹窗明确告知账号注销后不可恢复。
- 4.3.4 倒计时未结束时，Confirm 按钮置灰不可点击。
- 4.3.5 用户点击 Cancel 时，系统关闭弹窗且不执行注销。
- 4.3.6 倒计时结束后，Confirm 按钮变为可点击。
- 4.3.7 用户点击 Confirm 后，系统执行最终注销条件校验。
- 4.3.8 用户存在金币、钻石或可提现薪资时，系统拦截注销并提示先处理资产。
- 4.3.9 用户存在申请提现中订单时，系统拦截注销并提示先完成提现流程。

### 4.4 注销联动与协议版本
- 4.4.1 用户存在未结清预支工资时，系统提示“存在未结清的预支，无法注销账号”。
- 4.4.2 用户满足全部注销条件时，系统注销账号并清除登录状态。
- 4.4.3 用户注销成功后，系统释放 Google、Apple、手机号和邮箱绑定关系。
- 4.4.4 公会长注销成功时，系统自动解散所属公会。
- 4.4.5 公会长注销成功时，系统使公会内主播自动退出公会且无需审核。
- 4.4.6 主播注销成功时，系统自动退出所在公会且无需审核。
- 4.4.7 注销联动完成后，系统发送对应系统消息。
- 4.4.8 用户点击隐私政策或用户协议入口时，协议页面按当前语言展示。
- 4.4.9 协议加载失败时，系统提示稍后重试。

## 5. 首页内容发现模块
### 5.1 首页初始化与顶部入口
- 5.1.1 已登录用户进入首页时，系统加载顶部用户信息、Banner、Hot Rooms、Big shot、国家筛选和房间列表。
- 5.1.2 用户未设置头像时，首页顶部头像展示默认头像。
- 5.1.3 用户点击顶部头像时，页面进入个人中心或个人资料入口。
- 5.1.4 首页顶部展示 Min 和 Recommend 频道标签。
- 5.1.5 用户点击频道标签时，首页频道内容切换。
- 5.1.6 频道内容为空时，页面展示空状态。
- 5.1.7 用户点击搜索图标时，页面进入搜索页。
- 5.1.8 用户点击我的房间入口时，页面进入用户本人房间或我的房间页面。
- 5.1.9 首页数据加载失败时，页面展示缓存内容或错误提示并提供重试入口。

### 5.2 Banner与新人礼包
- 5.2.1 Banner 有运营配置时，首页展示 Banner 图片和文案。
- 5.2.2 Banner 无运营配置时，首页隐藏 Banner 区或展示默认运营图。
- 5.2.3 Banner 文案过长时，页面按视觉方案截断或换行。
- 5.2.4 用户点击有效 Banner 时，系统进入配置的活动页、礼包页、充值页或承接页。
- 5.2.5 用户点击已失效 Banner 时，页面停留首页并提示“活动暂不可用”。
- 5.2.6 新注册用户首次进入首页且注册设备账号下无其他账号时，系统展示新人礼包动效。
- 5.2.7 新人礼包动效播放完成后，系统展示 VIP1 3 天奖励弹窗。
- 5.2.8 用户点击“收下”后，奖励弹窗关闭并回到首页主界面。
- 5.2.9 不符合新人礼包条件的老用户进入首页时，不展示新人礼包动效。

### 5.3 Hot Rooms与Big shot
- 5.3.1 Hot Rooms 数据来源为本周房间榜单。
- 5.3.2 Hot Rooms 最多展示前 5 个房间。
- 5.3.3 Hot Rooms 默认视觉顺序按第 2、第 1、第 3、第 4、第 5 名展示。
- 5.3.4 Hot Rooms 榜单不足 5 个时，按实际数量展示且不出现空白卡片。
- 5.3.5 用户左右滑动 Hot Rooms 时，可查看不同名次房间。
- 5.3.6 用户点击可进入的热门房间卡片时，系统进入房间。
- 5.3.7 热门房间锁房或权限限制时，系统展示进入限制提示或校验入口。
- 5.3.8 热门房间已关闭时，系统提示“房间暂不可进入”并刷新热门房间数据。
- 5.3.9 Big shot 展示本周财富榜前 5 用户头像和昵称。

### 5.4 国家筛选、房间列表与热力值
- 5.4.1 国家筛选默认选中 All 且房间列表展示全部国家或地区房间。
- 5.4.2 国家标签由服务端返回，客户端不写死国家列表。
- 5.4.3 国家标签数量超过屏幕宽度时，支持横向滑动查看更多国家。
- 5.4.4 用户点击某国家标签后，房间列表刷新为该国家下的房间。
- 5.4.5 当前国家无房间时，房间列表展示空状态。
- 5.4.6 房间列表按房间热力值降序展示。
- 5.4.7 当房间当前在线人数为 100 且 60 分钟金币流水为 1000 时，热力值计算为 100×0.4+1000×0.6=640。
- 5.4.8 幸运礼物金币数为 1000 时，计入金币流水的数值为 100。
- 5.4.9 房间封禁、隐藏、删除、失效或命中用户黑名单时，首页所有曝光位均不展示该房间。

## 6. 搜索模块
### 6.1 搜索页入口与基础交互
- 6.1.1 用户点击首页顶部搜索入口后，页面进入搜索页。

- 6.1.3 无明确入口配置时，默认选中 Room 或上次用户使用的分类。

- 6.1.7 清空后点击 Search 时，系统不发起搜索请求。
- 6.1.8 搜索请求加载中时，页面展示加载态。
- 6.1.9 搜索请求失败时，页面展示失败提示并允许重试。

### 6.2 用户搜索
- 6.2.1 用户切换到 User 分类时，User Tab 展示选中态。
- 6.2.2 用户输入用户 ID 并点击 Search 时，系统按用户 ID 查找匹配用户。
- 6.2.3 用户输入靓号并点击 Search 时，系统查找到持有该靓号的用户。
- 6.2.4 用户输入昵称关键词并点击 Search 时，系统返回昵称模糊匹配用户。
- 6.2.5 用户 ID 或靓号精确命中时，精确结果优先展示。
- 6.2.6 用户搜索结果卡片展示头像、昵称、国家或地区、性别、用户 ID 和等级标签。
- 6.2.7 用户头像为空时，结果卡片展示默认头像。
- 6.2.8 用户昵称超长时，结果卡片按跑马展示。
- 6.2.9 用户点击可访问用户结果卡片时，页面进入该用户个人资料页。

- 6.3.1 用户切换到 Room 分类时，Room Tab 展示选中态。
- 6.3.2 用户输入房间 ID 并点击 Search 时，系统按房间 ID 查找匹配房间。
- 6.3.3 用户输入房间名称并点击 Search 时，系统返回房间名称匹配结果。
- 6.3.4 用户输入用户 ID 并点击 Search 时，Room 分类返回该用户关联房间。
- 6.3.5 用户输入靓号并点击 Search 时，Room 分类返回该靓号用户关联房间。
- 6.3.6 房间搜索结果精确匹配优先于模糊匹配。
- 6.3.7 房间搜索结果可进入房间优先于不可进入房间。
- 6.3.8 房间搜索结果卡片展示房间封面、房间名称和国家或地区标签。
- 6.3.9 用户点击可进入房间结果卡片时，系统进入房间。

### 6.4 Tab切换、过滤与异常
- 6.4.1 用户在 Room/User 间切换时，当前搜索词保持不变。
- 6.4.2 Room 分类只展示房间结果。
- 6.4.3 User 分类只展示用户结果。
- 6.4.4 当前分类无结果时，只展示当前分类无结果状态。
- 6.4.5 一个分类无结果时，不影响另一个分类已有结果。
- 6.4.6 Tab 切换有缓存结果时，页面直接展示对应分类缓存结果。
- 6.4.7 Tab 切换无缓存结果时，系统按当前搜索词请求对应分类结果。
- 6.4.8 点击封禁、注销或资料不可见用户结果时，系统展示不可访问提示。
- 6.4.9 点击关闭、封禁、回收、已满、锁房或权限不足房间结果时，系统展示不可进入原因。

## 9. 榜单过滤、隐身与展示好友入口
### 9.1 榜单过滤规则
- 9.1.1 财富榜用户被封禁时，系统从财富榜移除该用户。
- 9.1.2 魅力榜用户被封禁时，系统从魅力榜移除该用户。
- 9.1.3 房间被封禁时，系统从房间榜移除该房间。
- 9.1.4 房间被后台隐藏时，系统从房间榜移除该房间。
- 9.1.5 房主被封禁时，系统从房间榜移除该房间。
- 9.1.6 房间内普通成员被封禁时，不影响房间榜排名结果。
- 9.1.7 榜单过滤优先级高于排序。
- 9.1.8 榜单过滤优先级高于名次展示。
- 9.1.9 已上榜对象在展示后变为封禁或隐藏状态时，系统立即从对应榜单移除。

### 9.2 榜单隐身展示规则
- 9.2.1 用户具备榜单隐身权益时，当前用户排名提示区展示显示或隐藏入口。
- 9.2.2 用户不具备榜单隐身权益时，页面不展示显示或隐藏入口或提示需要权益。
- 9.2.3 榜单隐身默认关闭。
- 9.2.4 榜单隐身关闭时，财富榜对外展示真实头像和真实昵称。
- 9.2.5 榜单隐身关闭时，魅力榜对外展示真实头像和真实昵称。
- 9.2.6 用户开启榜单隐身后，财富榜对其他用户展示神秘人头像和昵称“神秘人”。
- 9.2.7 用户开启榜单隐身后，魅力榜对其他用户展示神秘人头像和昵称“神秘人”。
- 9.2.8 用户开启榜单隐身后，房间内榜单对其他用户展示神秘人头像和昵称“神秘人”。
- 9.2.9 用户关闭榜单隐身后，对其他用户恢复展示真实头像和真实昵称。

### 9.3 本人查看例外与排名统计
- 9.3.1 用户本人查看自己的当前用户排名提示区时，展示真实头像和真实昵称。
- 9.3.2 用户本人查看自己的榜单卡片时，展示真实头像和真实昵称。
- 9.3.3 用户本人查看自己的其他榜单信息时，不展示神秘人头像和昵称。
- 9.3.4 榜单隐身开启后，不改变真实榜单统计。
- 9.3.5 榜单隐身开启后，不改变真实榜单排名计算。
- 9.3.6 榜单隐身开启后，不改变奖励结算口径。
- 9.3.7 榜单隐身状态切换成功后，榜单页按最新展示状态刷新。
- 9.3.8 榜单隐身状态切换失败时，页面保留切换前状态。
- 9.3.9 榜单隐身权益过期后，入口不可继续生效且对外展示按服务端最新状态返回。

### 9.4 榜单对象访问与好友入口

- 9.4.5 用户点击封禁房间榜对象时，页面不进入房间并展示不可进入原因。
- 9.4.6 用户点击回收房间榜对象时，页面不进入房间并展示不可进入原因。
- 9.4.7 用户点击已满或权限不足房间榜对象时，页面不进入房间并展示不可进入原因。
- 9.4.8 用户进入财富榜、魅力榜或房间榜前三名时，前列展示位出现添加或更换展示好友入口。

## 10. 榜单展示好友设置模块
### 10.1 资格、入口与首次引导

- 10.1.6 用户首次成为魅力榜 TOP3 时，系统展示首次引导弹窗。
- 10.1.7 用户首次成为房间榜 TOP3 时，系统展示首次引导弹窗。
- 10.1.8 同一用户同一榜单已展示过首次提示后，系统不重复弹出首次引导。
- 10.1.9 用户在首次引导弹窗点击添加朋友后，系统打开添加好友展示弹窗。

### 10.2 添加好友弹窗与搜索
- 10.2.1 添加好友展示弹窗标题固定展示“添加好友展示”。
- 10.2.2 添加好友展示弹窗展示用户 ID 输入框。
- 10.2.3 添加好友展示弹窗展示搜索按钮。

- 10.2.5 无关注用户时，关注列表展示空状态。
- 10.2.6 用户 ID 输入为空时，点击搜索不发起搜索请求。
- 10.2.7 用户输入存在的用户 ID 并搜索时，系统展示匹配用户。
- 10.2.8 用户输入不存在的用户 ID 并搜索时，系统展示无搜索结果提示。

### 10.3 确认展示与设置保存
- 10.3.1 用户从关注列表点击添加后，系统校验该用户是否可作为展示好友。
- 10.3.2 候选好友可添加时，系统打开确认展示好友弹窗。
- 10.3.3 候选好友不可添加时，系统展示不可添加原因。
- 10.3.4 确认展示好友弹窗展示好友头像和好友昵称。
- 10.3.5 用户点击确认展示好友弹窗取消按钮时，返回添加好友展示弹窗且不保存选择。
- 10.3.6 用户点击确认按钮前，系统再次校验榜单资格、免费次数、好友状态和展示位状态。
- 10.3.7 校验通过后，系统保存展示好友关系。
- 10.3.8 设置成功后，榜单展示位刷新为已展示好友状态。
- 10.3.9 设置失败时，系统展示失败原因且保留原展示状态。

### 10.4 更换、付费与匿名例外
- 10.4.1 已设置展示好友的榜位展示好友头像、昵称和更换入口。
- 10.4.2 用户点击更换入口时，系统判断当前用户是否仍具备更换资格。
- 10.4.3 用户掉出 TOP3 后点击更换入口时，系统不允许新增或更换展示好友。
- 10.4.4 TOP1 用户首次设置展示好友时，系统消耗终身 1 次免费机会。
- 10.4.5 TOP1 免费机会用完后再次设置或更换时，系统按配置扣费。
- 10.4.6 配置金币为 0 时，系统不扣费并允许直接设置或更换。
- 10.4.7 付费更换金币不足时，系统提示余额不足且不改变原展示好友。
- 10.4.8 扣费失败时，系统不进入更换流程且不清空原展示好友。
- 10.4.9 被展示好友开启榜单匿名时，榜单好友展示位仍展示该好友真实头像。

## 11. 权限、边界、多语言与中断回退
### 11.1 身份权限与直接调用
- 11.1.1 未登录用户直接访问设置页时，系统引导登录且不返回设置数据。
- 11.1.2 未登录用户直接访问编辑资料页时，系统引导登录且不返回资料数据。
- 11.1.3 无榜单匿名权益用户直接调用榜单隐身开关接口时，服务端拒绝生效。
- 11.1.4 非 TOP3 用户直接调用设置展示好友接口时，服务端拒绝保存展示关系。
- 11.1.5 免费次数已用完用户绕过前端直接调用免费更换接口时，服务端按付费规则处理。
- 11.1.6 无创建房间权限用户直接调用创建房间接口时，服务端拒绝创建房间。
- 11.1.7 中国大陆 IP 用户直接调用登录接口时，服务端拒绝写入登录态。
- 11.1.8 中国大陆 IP 用户直接调用注册资料提交接口时，服务端拒绝创建或补全账号。
- 11.1.9 注销条件不满足用户直接调用注销接口时，服务端拒绝注销。

### 11.2 数值边界与分页刷新
- 11.2.1 房间当前在线人数为 0 且 60 分钟金币流水为 0 时，热力值计算为 0。
- 11.2.2 房间当前在线人数为负数时，系统拒绝参与热力值计算或按异常数据处理。
- 11.2.3 房间 60 分钟金币流水为负数时，系统拒绝参与热力值计算或按异常数据处理。
- 11.2.4 幸运礼物金币数为 0 时，计入金币流水数值为 0。
- 11.2.5 幸运礼物金币数不能被 10 整除时，换算结果按服务端精度策略展示。
- 11.2.6 榜单仅 1 条数据时，前列展示区只展示第一名。
- 11.2.7 榜单恰好 6 条数据时，前列展示区展示第一至第六名且普通列表为空或从第七名开始。
- 11.2.8 榜单超过一页时，普通列表翻页后排名序号连续。
- 11.2.9 筛选后榜单或房间列表为空时，页面展示空状态而不是空白页面。

### 11.3 多语言与阿拉伯语布局
- 11.3.1 登录模块中文环境下，按钮、提示和协议文案完整展示。
- 11.3.2 登录模块英文环境下，不展示未翻译 key。
- 11.3.3 登录模块阿拉伯语环境下，输入框、按钮和协议文案不重叠。
- 11.3.4 注册资料补全页英文标题 Complete your profile 展示完整。
- 11.3.5 设置模块英文标题 Settings、Account Settings、Change Password 展示完整。
- 11.3.6 首页英文区块 Hot Rooms 和 Big shot 展示完整。
- 11.3.7 搜索页英文 Room、User、Search 文案展示完整。
- 11.3.8 榜单页阿拉伯语环境下，榜单类型、周期按钮和排名卡片不发生错列。
- 11.3.9 榜单展示好友弹窗阿拉伯语环境下，好友昵称、按钮和金币提示不遮挡。

### 11.4 中断、取消与幂等
- 11.4.1 用户在登录提交后断网时，页面展示网络异常并允许重试。
- 11.4.2 用户在注册资料提交后断网时，页面保留已填内容并允许重试。
- 11.4.3 用户在邮箱验证码发送后切后台再返回时，倒计时继续按实际剩余时间展示。
- 11.4.4 用户在修改密码提交中重复点击确认按钮时，系统只提交一次修改请求。
- 11.4.5 用户在创建房间提交中重复点击创建入口时，系统只创建一个房间。
- 11.4.6 用户在榜单类型快速连续切换时，页面最终展示最后一次选中榜单的数据。
- 11.4.7 用户在榜单周期快速连续切换时，页面最终展示最后一次选中周期的数据。
- 11.4.8 用户在付费更换展示好友扣费中关闭弹窗时，扣费未成功则不改变原展示好友。
- 11.4.9 用户 token 过期时提交展示好友设置，系统拒绝保存并引导重新登录。

## 12. 数据一致性、埋点与待确认项
### 12.1 跨页面数据一致性

- 12.1.2 注册资料保存成功后，个人资料页展示的新头像与注册提交头像一致。
- 12.1.3 注册资料保存成功后，搜索结果中的用户昵称与最新昵称一致。
- 12.1.4 编辑资料保存成功后，直播间半屏资料页展示资料与编辑结果一致。
- 12.1.5 账号绑定手机号成功后，账号管理页展示最新手机号状态。

- 12.1.9 榜单展示好友设置成功后，榜单展示位返回的好友 ID 与确认弹窗中的好友 ID 一致。

### 12.2 日志、埋点与审计
- 12.2.1 登录失败日志区分账号不存在、密码错误、封禁、授权失败和网络异常。
- 12.2.2 中国大陆 IP 登录拦截日志记录拦截原因和登录方式。
- 12.2.3 中国大陆 IP 注册拦截日志记录拦截原因和注册来源。
- 12.2.4 搜索行为日志记录搜索词、分类 Tab 和结果数量。
- 12.2.5 房间创建日志记录创建人、默认房间名称和创建结果。
- 12.2.6 榜单隐身切换日志记录用户、切换前状态和切换后状态。
- 12.2.7 榜单展示好友付费更换日志记录扣费金额和更换结果。
- 12.2.8 注销账号日志记录最终校验失败原因或注销成功状态。
- 12.2.9 公会长注销联动日志记录公会解散和主播退出结果。

### 12.3 配置变更与缓存
- 12.3.1 服务端新增国家配置后，注册国家列表和首页国家筛选可展示新增国家。
- 12.3.2 服务端删除国家配置后，注册国家列表和首页国家筛选不展示已删除国家。
- 12.3.3 Banner 配置变更后，首页刷新展示最新 Banner。
- 12.3.4 Hot Rooms 业务刷新周期到达 60 分钟时，首页按最新本周房间榜刷新。
- 12.3.5 Big shot 业务刷新周期到达 60 分钟时，首页按最新本周财富榜刷新。
- 12.3.6 房间列表自动排序周期到达 60 分钟时，按最新热力值刷新排序。
- 12.3.7 房间封禁或隐藏状态变化时，首页不等待 60 分钟刷新即移除房间。
- 12.3.8 榜单对象封禁或隐藏状态变化时，榜单不等待周期刷新即移除对象。
- 12.3.9 新旧客户端灰度期间，服务端返回字段缺省时页面不崩溃。

- 12.4.1 待确认：登录方式切换时已输入内容是否保留，产品确认后回归手机号页和邮箱页切换场景。

- 12.4.5 待确认：Hot Rooms 选中第 N 名时隐藏相邻名次的通用算法，产品确认后回归第 1、第 2、第 5 名边界。
